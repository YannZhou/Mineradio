# Mineradio 2.2.0 Linux / 酷狗概念版适配版

> 基于上游 [XxHuberrr/Mineradio](https://github.com/XxHuberrr/Mineradio) **v2.2.0**（官方原版是 Windows 版），
> 由 [YannZhou](https://github.com/YannZhou) 补齐 **Linux 适配**与**酷狗音乐概念版全流程**，
> 在 Linux 上装完即用：deb 一键安装，扫码登录、搜索、播放、歌词、歌单、VIP 全链路打通。

---

## 一句话总结这一版

**底子从上游 2.0.3 换成了 2.2.0**（上游这期间发了 2.1.0、2.2.0 两个版本），
**酷狗概念版从"能用"升级到"省心"**：登录不再起额外进程、设备身份会记住、听歌自动领 VIP、手机上改了会员状态一键同步。

## 一、底子整体换新（上游 2.0.3 → 2.2.0 带来的）

这些是上游官方这几个月的改动，现在你也能用上了：

- **本地曲库**：可以把本地音乐导入应用，自动读取封面、时长，同名 `.lrc` 和内嵌歌词都能识别
- **播放与登录更稳**：三大音乐接口（网易云 / QQ 音乐 / 酷狗标准版）的登录、账号识别、播放稳定性修复
- **汽水音乐登录链路重做**：官方授权 + 扫码，比之前那套稳定
- **更好玩**：新增粒子预设、更多手势操作；桌面模式 / 全屏与 Wallpaper Engine 壁纸兼容性改善
- **更耐用**：歌单加载、搜索分页、断网恢复改善；长时间运行与连续播放更稳
- 上游另外发了 macOS 预览版（与本包无关）

## 二、Linux 适配（延续上一版，全部保留）

- **显卡走 OpenGL**（`use-angle=gl`），避免 NVIDIA 环境下渲染异常
- **内存管理对 Linux 放开**：既能用系统的"内存整理"，也新增了 Linux 内存回收
  （读 `/proc/meminfo` 做前后对比，走 `drop_caches` / `compact_memory`，需要时用 `pkexec` 提权）
- **打包**：`npm run build:linux` 直接出 deb，装到 `/opt/Mineradio`，桌面项自带
  `--no-sandbox --ozone-platform=x11`，X11 下开箱即用
- **禁用鼠标侧键**：防止误触"后退/前进"把界面刷掉

## 三、酷狗音乐概念版（本轮重点升级）

### 1. 扫码登录更快更干净

以前登录要另起一个 9488 端口的 Node 子进程（而且路径写死成 `/usr/bin/node`，Windows 上根本起不来）。
现在改成**进程内直接调用**：少一个进程、少一个端口、没有启动时序问题，扫码出码更快。

### 2. 设备身份会记住了

guid / mid / dev / webgl / mac / dfid 全部落盘保存（`userData/kugou-device.json`），重启后复用；
MAC 取的是**真实网卡地址**，不再是固定占位值。以前每次启动都换一套设备身份，容易触发平台风控。

### 3. 听歌自动领一天 VIP 🎁

每次播放时会自动补领当天的概念版 VIP，**一天只领一次**（本地记账，换账号当天可重新领），
失败会自动重试但不会反复骚扰接口。控制台能看到 `[KugouDailyVip] ... ok:true`。

### 4. 听歌奖励自动上报

一首歌**自然播完**后自动上报（每天有次数上限，已领取不会重复提交）。

### 5. 登录面板右上角新增「刷新状态」🔄

以前：在手机 App 里领了 VIP，电脑这边死活不同步，得**退出登录再重登**。
现在：登录面板**右上角**点一下「刷新状态」，立刻重新拉取账号信息与会员状态，
弹窗会告诉你「VIP / SVIP，到期 xxxx-xx-xx」。

## 四、本地歌词（延续上一版）

- 优先读**同目录同名 `.lrc`**
- 没有就读音频文件里的**内嵌歌词标签**
- 都没有，就按「歌名 + 歌手」**在线搜索兜底匹配**（带标题/歌手变体和相似度打分）
- 与上游新的"本地曲库"共存：导入曲库后依然走这套识别

## 五、给爱折腾的人：工程侧改动

- **依赖声明补全**：以前 `axios / crypto-js / node-forge / pako / big-integer / qrcode /
  safe-decode-uri-component` 只存在于本地手装的 `kugou-server/node_modules`，
  别人克隆仓库根本构建不出来。现在都写进 `package.json`，全新 `clone + npm install` 即可构建。
- **打包瘦身**：排除 `kugou-server` 的 `node_modules / docs / public` 等无关内容，应用目录 61 MB → 49 MB。
- **去掉子进程**：不再需要 `express` / `dotenv`（只有被删掉的 HTTP 入口用）。
- **模块审计**：前端 103 个模块确认无死文件；`kugou-server` 161 个接口模块里实际只用到 17 个。

## 六、已知限制

- 酷狗概念版音质上限是**无损 FLAC**（没有 Hi-Res / 至臻），请求高音质会自动降级
- **未登录**时播放 VIP 歌曲会提示"需要官方安全验证"，属于平台侧限制，先扫码登录即可
- 上游原来的"打开官方网页登录窗口"已经没有入口了（酷狗走概念版扫码），但**手动导入 Cookie** 仍然可用

## 七、安装

```bash
sudo dpkg -i mineradio_2.2.0_amd64.deb
# 如果提示缺依赖：
sudo apt-get -f install
```

装完在应用菜单里搜 **Mineradio** 即可。升级安装直接覆盖，登录态保留。
