# Mineradio Linux / 酷狗概念版适配版

基于上游 [Mineradio](https://github.com/XxHuberrr/Mineradio)（原版只有 Windows）的 **Linux 适配版本**。界面、视觉与操作保持上游原样，本版只做两件事：让它在 Linux 上装完即用，以及把上游还没做的**酷狗音乐概念版**与**本地歌词**补齐。

**Linux 侧** —— 渲染走 OpenGL（避开 NVIDIA 环境下的异常），内存整理支持 Linux（含系统级内存回收），deb 一键安装到 `/opt/Mineradio`，并禁用鼠标侧键防止误触刷新。

**酷狗概念版** —— 扫码登录改为进程内完成，不再额外起一个子进程和端口；设备身份会落盘记住，重启不必重新"认设备"；**听歌自动领取每日 VIP**，一首歌听完自动上报听歌奖励；登录面板右上角新增「刷新状态」，手机上领了会员一键同步，不用再退出重登。

**本地歌词** —— 优先读同目录同名 `.lrc`，其次读音频内嵌歌词，都没有就按歌名 + 歌手在线兜底匹配。

**工程侧** —— 依赖声明补全，克隆仓库后可直接构建；打包剔除了与运行无关的内容。

## 安装

```bash
sudo dpkg -i mineradio_2.2.0_amd64.deb
```

装完在应用菜单里搜 **Mineradio** 即可，升级安装直接覆盖、登录状态保留。

## 已知限制

- 酷狗概念版音质上限为无损 FLAC，请求更高音质会自动降级
- 未登录时播放 VIP 歌曲会提示"需要官方安全验证"，扫码登录后即可正常播放
