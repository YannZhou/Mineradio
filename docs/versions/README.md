## 版本号与上游的关系

本仓库是 [XxHuberrr/Mineradio](https://github.com/XxHuberrr/Mineradio) 的 Linux 适配分支，版本号沿用所基于的上游版本号（例如 `2.2.0` 表示基于上游 `v2.2.0`），
适配版自身用独立的 Git 标签区分（如 `v2.2.0-linux`），避免与上游标签冲突。

上游已发布长期停更声明，此后适配版在**保持上游基线不变**的前提下启用补丁位：
`2.2.x` 表示基线仍为上游 `v2.2.0` 的适配版第 N 次发布（如 `2.2.1` = 第 2 次），
标签仍带 `-linux` 后缀（如 `v2.2.1-linux`），与上游可能出现的同名标签区分。

软件的界面、视觉与功能设计来自上游作者，本适配版只负责平台适配与第三方平台接入的补齐。
