## 一、酷狗音乐概念版全流程适配

把酷狗的整个链路从**标准版**换成**概念版（lite）**，参考项目为 EchoMusic 的 KuGouMusicApi 接入方式。

### 1.1 新增内嵌调用层 `kugou-lite.js`

- 在 `server.js` 进程内直接 `require` `kugou-server` 的模块，**不做 HTTP 转发**
  （无端口与启动时序依赖，签名与设备注册复用现成实现）
- 关键点：
  - `process.env.platform = 'lite'` 必须在加载任何 `kugou-server` 模块**之前**设置，
    否则会使用标准版 appid
  - 设备状态（guid / mid / dev / mac / webgl）进程内生成一次；`dfid` 调 `register_dev` 获取并缓存
  - `register_dev` 必须带设备 cookie（uuid / imei 取自 `KUGOU_API_GUID`），否则解密失败
  - 请求必须携带完整登录 cookie，且 `userid` 必须是**字符串** `'0'`（数字 0 会被判为假值而丢弃，
    导致签名参数集不同，接口返回 `error_code 152`）

### 1.2 内嵌 `kugou-server/`

- 将 KuGouMusicApi 的快照随仓库与安装包提供，概念版所需的签名、设备注册、接口封装都在其中
- 清除了配置里上游携带的微信 AppID / Secret（安全考虑，避免密钥泄露告警）

### 1.3 `server.js` 接线（概念版优先、标准版兜底）

- 搜索、音源、歌词、登录态、用户信息、歌单列表、歌单曲目共 7 处改为先走概念版
- 扫码成功后由主进程把 `token / userid` 写回服务端 `kugouCookie`
  （新增 `saveKugouCookie / getKugouCookie` 导出），否则登录状态识别不出来

### 1.4 扫码登录

- 主进程新增 `kugou-music-qr-create / kugou-music-qr-check` 两个 IPC，
  并在 `preload.js` 暴露给前端
- **二维码必须使用官方返回的图**：`/login/qr/key` 响应里的 `qrcode_img`
  （内容是 `https://h5.kugou.com/apps/loginQRCode/html/index.html?appid=3116&qrcode=KEY`）；
  自行用 `/login/qr/create` 拼 URL 生成的二维码 App 无法关联 key，会导致扫码后一直"等待中"
- 轮询状态做数字归一化：`0` 过期 / `1` 待扫 / `2` 已扫待确认 / `4` 成功
- 服务端的接口缓存需要放行扫码状态查询接口，否则"等待中"被缓存 2 分钟，用户确认后仍轮询不到

### 1.5 数据格式适配（概念版与标准版字段不同）

- 搜索结果：概念版返回 `data.lists`，字段（`FileName / SingerName / FileHash / MixSongID / OriSongName` 等）
  与既有转换函数兼容；需把 `OriSongName` 补到 `SongName`，避免歌名里带歌手
- 用户歌单：返回 `data.info`（不是 `data.list / lists`）；只显示本人创建的歌单，
  过滤掉混入的他人歌单
- 歌单曲目：返回 `data.songs`（不是 `plist / list`）；`name` 形如「歌手 - 歌名」需要拆分，
  `timelen` 毫秒转秒，`relate_goods` 提取高音质 hash 供播放使用
- 会员状态：顶层 `is_vip: 0` 具有误导性，真实会员信息在 `data.busi_vip[]` 中逐项判断
- 播放地址：概念版返回的 `url` 是**逗号分隔的多地址**，必须取第一个，
  否则前端通过音频代理请求整串地址会失败并提示"不可播放"

### 1.6 音质

- 概念版最高音质为**无损 FLAC**（无 Hi-Res / 至臻），请求更高音质时自动降级
- 前端音质选项补入「无损 FLAC / 酷狗概念版最高音质」

## 二、本地音乐歌词识别

本地音乐文件播放时自动匹配歌词，优先级如下：

1. **同目录同名 `.lrc` 文件**（含 BOM 清理）
2. **音频内嵌歌词标签**（ID3 / FLAC / M4A 等，兼容同步歌词字段）
3. **在线兜底匹配**：按「歌名 + 歌手」搜索，支持标题 / 歌手变体与相似度打分筛选

配套改动：

- 主进程新增 `readLocalLyricFromFile()` 与对应 IPC
- 拖拽导入本地文件时通过 `getPathForFile` 取得真实磁盘路径，供歌词读取使用

## 三、前端交互修复（Mineradio 特有）

- **二维码不显示**：登录面板的 `web-login-preview` 样式会隐藏二维码图片，
  酷狗需要排除在该样式之外
- **登录弹窗自动消失**：解锁动画结束后的回调会关闭登录抽屉，把用户刚点开的二维码面板关掉；
  需要在回调里判断"当前是否正在显示酷狗二维码"再决定是否关闭
- **弹窗被重置**：启动引导的定时器会延迟弹出其他平台的登录引导，
  需要改为定时器句柄化 + 触发时二次检查弹窗状态

## 五、已知限制

- 概念版无 Hi-Res / 至臻音质，最高为无损 FLAC
- 未登录时播放 VIP 歌曲会提示"需要官方安全验证"，需要先扫码登录
- 需要设备身份稳定的场景（例如平台风控）在本版尚未处理：设备标识仍是每次启动随机生成；
  该问题在 `v2.2.0-linux` 中修复
