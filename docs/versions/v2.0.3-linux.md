- 应用版本号：`2.0.3`

- 基线：上游 `XxHuberrr/Mineradio` **v2.0.3**（上游原版只有 Windows）

## 适配内容

### 1. 渲染后端：Direct3D → OpenGL

- `desktop/main.js`：`use-angle` 由 `d3d11` 改为 `gl`
  （Linux 没有 Direct3D，使用 d3d11 会导致渲染异常/黑屏）
- 改动共 6 行，涉及启动开关表与内存/GPU 参数对象两处

### 2. Linux 系统内存回收（本版新增，约 200 行）

- `desktop/system-memory.js` 新增 Linux 实现：
  - 读取 `/proc/meminfo`，记录清理前后的可用内存与占用率
  - 依次执行 `sync`、`echo 3 > /proc/sys/vm/drop_caches`、`echo 1 > /proc/sys/vm/compact_memory`
  - 无权限时通过 `pkexec`（桌面 polkit 弹窗）提权，权限被拒也不影响应用运行
  - 返回结构与本程序 Windows 版一致（释放量、前后负载、各步骤是否成功）
- 同时把"自动内存整理"的开关对 Linux 放开（原先只对 Windows 生效）

### 3. 交互修正：鼠标侧键拦截

- `public/js/index-loader.js`：拦截鼠标侧键（后退 / 前进）默认行为，
  避免在应用内误触导致页面回退重载

### 4. 打包：deb

- `package.json` 新增 Linux 打包配置：
  - 目标 `deb`（x64）、图标 `build/icon.png`、分类 `Audio`
  - 桌面启动参数 `--no-sandbox --ozone-platform=x11`，保证 X11 会话下可直接启动
- 新增 `npm run build:linux` 脚本

### 5. 其他

- 修正 `license` 的 SPDX 标识（`GPL-3.0-only` → `GPL-3.0`）
- README 补充 Linux 下载与开发说明，并新增《Linux 适配说明》文档
