## 一、基线升级：上游 2.0.3 → 2.2.0

上游在 v2.0.3 之后发布了 2.1.0 与 2.2.0，本版先把上游整包吃进来，再重新落地本仓库的适配内容。

**上游这两个版本带来的（用户可感知）**

- 三大音乐接口（网易云 / QQ 音乐 / 酷狗标准版）的登录、账号识别、播放稳定性修复
- 新增本地曲库：可导入本地音乐，自动读取封面与时长，同目录同名 `.lrc` 与内嵌歌词都能识别
- 汽水音乐登录链路重做（官方授权 + 扫码）
- 新增粒子预设与更多手势操作；桌面模式 / 全屏与 Wallpaper Engine 壁纸兼容性改善
- 歌单加载、搜索分页、断网恢复改善；长时间运行与连续播放更稳定

**代码层面新增的主要模块**

- `desktop/local-music-library.js`（本地曲库，含媒体协议与导入能力）
- `desktop/built-in-playlist-library.js`（内置歌单库）
- `qishui-auth-v6.js` + `qishui-qr-login.js`（汽水登录重写）
- `cuefield/` 自动混音模块大幅扩充、手势控制模块扩充、`public/css/index.css` 大量样式调整

**移植方式（重要）**

本仓库与上游仓库历史互不相关，因此**不使用 merge**，而是：

1. 把 `v2.0.3 → v2.0.4` 的全部适配改动抽成补丁，打到干净的 `v2.2.0` 树上
2. 补丁共 259 个 hunk，**245 个自动落地**，14 个冲突块人工合并
   - `desktop/main.js` 3 块（子进程启动段、二维码 IPC、启动调用）
   - `desktop/preload.js` 2 块（`webUtils` 引入、二维码登录方法暴露）
   - `public/js/modules/08-account/03-login-modal-flows.js` 3 块（二维码显示与弹窗竞态）
   - `package.json` 2 块（打包文件清单、Linux 打包配置）
   - `README.md` 4 块（本版改为重写，不做合并）
3. `server.js` 的酷狗概念版接线**零冲突**落地

## 二、Linux 适配（延续既有适配，全部保留）

- **渲染后端**：`use-angle` 由 `d3d11` 改为 `gl`（`desktop/main.js` 两处），避免 NVIDIA 环境下的渲染异常
- **内存管理**：`scheduleAppMemoryTrim` 对 Linux 放开；`desktop/system-memory.js` 提供 Linux 内存回收实现
  （读取 `/proc/meminfo` 做前后对比，调用 `drop_caches` / `compact_memory`，需要提权时使用 `pkexec`）
- **打包与安装**：`npm run build:linux` 产出 deb；`linux.icon / category / maintainer` 与
  `executableArgs: ["--no-sandbox", "--ozone-platform=x11"]` 已配置，安装后桌面菜单可直接启动
- **交互修正**：`public/js/index-loader.js` 拦截鼠标侧键（后退 / 前进），避免误触导致界面重载

## 三、酷狗音乐概念版

### 3.1 全链路（沿用 2.0.4，在 2.2.0 基线上重新落地）

- `kugou-lite.js`：进程内调用层，直接加载 `kugou-server` 的模块
  （`search / search_lyric / lyric / song_url / user_detail / user_vip_detail / user_playlist /
  playlist_track_all / register_dev`），签名与设备注册复用其 `util`
- `kugou-server/`：KuGouMusicApi 的快照，随仓库与安装包提供
- `server.js` 接线：搜索、音源、歌词、登录态、用户信息、歌单列表、歌单曲目共 7 处概念版优先、
  标准版兜底；并导出 `saveKugouCookie / getKugouCookie` 供主进程在扫码成功后写回登录态

### 3.2 扫码登录改为进程内调用（本版新增）

- 移除原先 spawn `app.js` 起的 9488 HTTP 子进程与 `kugouApi()` HTTP 封装
  （原实现硬编码 `/usr/bin/node`，在 Windows 上必然启动失败，且存在 500ms 启动竞态）
- `kugou-lite.js` 新增 `liteQrKey / liteQrCreate / liteQrCheck`，直接调用
  `login_qr_key / login_qr_create / login_qr_check` 模块（web 加密，不需要 dfid）
- 扫码状态统一做字符串归一化后比较，兼容返回数字或字符串两种形式

### 3.3 设备身份持久化（本版新增）

- `guid / mid / dev / webgl / mac / dfid` 全部落盘到 `userData/kugou-device.json`（权限 0600），跨启动复用
- MAC 取**真实网卡地址**（`os.networkInterfaces()`，跳过内部接口），失败才退回占位值
- `dfid` 注册结果一并落盘，重启后直接读取，不再重复注册
- `resetDevice()` 语义明确为「显式重置设备身份」并删除落盘文件；退出登录 / 会话过期**不调用**它，
  以保证设备身份稳定（此前每次启动随机生成设备标识，容易触发平台风控）

### 3.4 每日 VIP 自动领取（本版新增）

- 接口：`POST /youth/v1/recharge/receive_vip_listen_song`（模块 `youth_day_vip`），
  `source_id` 先 `90139`、失败再试 `90137`
- **必选参数 `receive_day` 必须是 `YYYY-MM-DD` 本地日期**，实测返回码：
  - 不传 → `20006 err signature`（伪装成签名错误）
  - 格式不对（`1` / `20260917` / 时间戳）→ `304001 日期格式错误`
  - 日期早于今天 → `304003 日期不能小于今天`
  - 当天已领取 → `131001`（无错误文案）
  - 领取成功 → `status: 1` 并返回计数器数据
- 触发方式：每次取歌（`/api/kugou/song/url`）自动补领；也可手动
  `GET /api/kugou/vip/daily-claim[?force=1]`
- 记账文件：`userData/kugou-reward-state.json`，按 **账号 + 自然日** 去重
  （换账号当天可重新领取）；自动触发每日最多 4 次、两次间隔不少于 10 分钟
- 领取成功后会清空酷狗会话与会员缓存，使会员状态立即生效

### 3.5 听歌奖励自动上报（本版新增）

- 接口：`POST /youth/v2/report/listen_song`（模块 `youth_listen_song`），
  `clientver=10566` 与专用 UA，必须传真实 `mixsongid`；「今日已领取」码为 `130012`
- 触发时机：一首歌**自然播完**后（前端 `finalizeListenSession(completed = true)`），
  同一首不重复上报；服务端按账号 + 自然日去重，单日最多 8 次

### 3.6 登录面板「刷新状态」按钮（本版新增）

- 问题背景：在手机 App 里领取会员后，电脑端长时间不同步，需要退出登录再重登
- 后端 `GET/POST /api/kugou/login/refresh`：重新读取 cookie 文件 + 清空酷狗会话缓存
  （原 VIP 缓存 5 分钟、正向会员还有 10 分钟宽限）+ 重新拉取账号资料与会员信息，
  并附带概念版会员到期数据
- 前端：登录面板**右上角**新增「刷新状态」按钮，点击后刷新账号状态并提示
  「VIP / SVIP，到期 xxxx-xx-xx」

## 四、本地歌词识别（沿用 2.0.4）

- 优先读取**同目录同名 `.lrc`**；其次读取音频文件的**内嵌歌词标签**（ID3 / FLAC / M4A 等）
- 以上都没有时，按「歌名 + 歌手」**在线搜索兜底匹配**，带标题 / 歌手变体与相似度打分
- 与上游新增的本地曲库并存：导入曲库后的本地文件同样走这套识别

## 七、已知限制

- 酷狗概念版音质上限为**无损 FLAC**（无 Hi-Res / 至臻），请求更高音质会自动降级
- **未登录**时播放 VIP 歌曲会提示"需要官方安全验证"，扫码登录后即可正常播放
- 上游原本的"打开官方网页登录窗口"在酷狗上已无入口（改为概念版扫码登录），
  但**手动导入 Cookie** 的方式仍然可用

## 八、安装与构建

```bash
# 安装
sudo dpkg -i mineradio_2.2.0_amd64.deb
# 如提示缺少依赖
sudo apt-get -f install
```

```bash
# 从源码构建
git clone https://github.com/YannZhou/Mineradio.git
cd Mineradio
npm install --include=dev
node node_modules/electron/install.js   # 若 npm 因 allow-scripts 白名单未下载 Electron
npm start                                # 开发运行
npm run build:linux                      # 打包 deb 到 dist/
```

> 若环境中设置了 `ELECTRON_RUN_AS_NODE`，运行 Electron 前需先 `unset`，否则会被当作纯 Node 执行。
