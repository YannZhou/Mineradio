## 适配内容

### 1. GPU 渲染修复

- `desktop/main.js`：图形后端 `use-angle` 由 `d3d11` 改为 `gl`
- 背景：Mineradio 是为 Windows 开发的 Electron 应用，默认使用 Direct3D 后端；
  在 Linux 上该后端不可用，会出现窗口空白、渲染失败或直接退出

### 2. 鼠标侧键拦截

- `public/js/index-loader.js`：拦截鼠标侧键（button 3 / 4）的默认行为
- 背景：鼠标侧键在 Electron 里等同"后退/前进"，误触会让整个界面回退重载

### 3. deb 打包支持

- `package.json` 新增 Linux 打包配置：
  - 打包目标 `deb`（x64）
  - 桌面启动参数 `--no-sandbox --ozone-platform=x11`
    （未签名应用在部分发行版上需要关闭沙箱；显式指定 X11 平台避免 Wayland 下的兼容问题）
- 由此产出可直接 `dpkg -i` 安装的安装包，安装到 `/opt/Mineradio`

## 已知限制（当时状态）

- 内存管理、第三方平台登录、音质档位等仍按 Windows 行为工作，未做 Linux 适配
- 系统级内存回收在 Linux 上不可用（在 v2.0.3-linux 中补齐）
